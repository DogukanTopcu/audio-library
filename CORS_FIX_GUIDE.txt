## 🔧 CORS FIX - How to Run the Project

### Problem

### Solution Applied
✅ Updated CORS configuration to allow port 3001

---

## 🚀 HOW TO RUN

### 1. Start the API Server
```bash
cd apps/api
npm run start:dev
```

API will run on: **http://localhost:3001**

Swagger docs available at: **http://localhost:3001/api/docs**

### 2. Start the Admin App
```bash
cd apps/admin
npm run dev
```

Admin app will run on: **http://localhost:3000**

### 3. Start the Web App
```bash
cd apps/web
npm run dev
```

Web app will run on: **http://localhost:3002**

## 📡 API Endpoints

The API is available at: **http://localhost:3001/api**

Common endpoints:
- `GET /api/content` - List all books
- `GET /api/kesfet/:contentId` - Kesfet details page ⭐ NEW
- `POST /api/auth/login` - Login
- `GET /api/player/progress` - Get listening progress
- `GET /api/questions/chapter/:id` - Get questions
- `GET /api/ilerleme` - Get progress

Complete API docs at: **http://localhost:3001/api/docs**

```bash
# Seed sample data
npm run db:seed
```

## 🎯 Quick Start (All at Once)

1. **Setup DB**
```bash
cd packages/db
npm run db:migrate
npm run db:seed
cd ../..
```

2. **Start API** (in new terminal)
```bash
cd apps/api
npm run start:dev
```

3. **Start Admin** (in new terminal)
```bash
cd apps/admin
npm run dev
```

4. **Start Web** (in new terminal)
```bash
cd apps/web
npm run dev
```

Then visit:
- **Admin**: http://localhost:3000
- **Web**: http://localhost:3002
- **API Docs**: http://localhost:3001/api/docs
