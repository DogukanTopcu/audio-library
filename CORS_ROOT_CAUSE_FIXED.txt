## ✅ CORS FIX - ROOT CAUSE FOUND & FIXED

### The Real Problem
The frontend axios clients were missing `withCredentials: true` configuration, which is required for CORS requests to work properly.

---

## 🔧 What Was Fixed

### File 1: apps/web/src/lib/api.ts
```typescript
// BEFORE (missing withCredentials)
const api = axios.create({
  baseURL: API_URL,
  headers: { 'Content-Type': 'application/json' },
});

// AFTER (added withCredentials)
const api = axios.create({
  baseURL: API_URL,
  headers: { 'Content-Type': 'application/json' },
  withCredentials: true,  // ✅ ADDED
});
```

### File 2: apps/admin/src/lib/api.ts
```typescript
// BEFORE (missing withCredentials)
```

## ✅ Why This Fixes It

**withCredentials: true** tells the browser:
- Allow sending credentials (cookies, auth headers) across domains
- Allow cross-origin requests
- Properly handle CORS preflight requests

Without it, the browser blocks the request before it even reaches the server.
