## 🎯 THE KESFET DETAILS PAGE

### What It Does
When user clicks on a book in Kesfet:
1. Shows all chapters and subchapters (hierarchical tree)
2. Displays progress for each chapter (audio % and questions %)
3. Shows count of audios and questions
4. Provides buttons to navigate to:
   - Ders Dinle (audio player)
   - Soru Çöz (questions)

### How It Works

**User Flow:**
```
Kesfet page (books list)
    ↓
User clicks book
    ↓
GET /kesfet/details/:contentId
    ↓
Kesfet Details Page
├─ Book title
├─ Hierarchical chapters
│  ├─ Chapter 1
│  │  ├─ Audio: 3/2 completed (67%)
│  │  ├─ Questions: 5 solved, 4 correct (80%)
│  │  ├─ [Ders Dinle] → /player/chapter/ch1
│  │  └─ [Soru Çöz] → /questions/chapter/ch1
│  ├─ Chapter 2
│  │  └─ ...
│  └─ Chapter 1.1 (sub-chapter)
│     └─ ...
└─ Navigation
```

### Sidebar Navigation
When in audio player or questions, sidebar shows:
```
GET /kesfet/tree/:contentId
    ↓
Chapter tree
├─ Chapter 1 (current)
├─ Chapter 2
└─ Chapter 1.1
```
