## 📡 The Endpoint

```
GET /kesfet/:contentId
```

**When to use**: After user clicks on a book in the Kesfet page

**What it returns**: Complete page data with:
- Book information
- All chapters and subchapters (hierarchical)
- Ders Dinle section (audio player with progress)
- Soru Çöz section (questions with progress)
- İlerleme section (progress tracking and retry)

```typescript
  headers: { 'Authorization': `Bearer ${token}` }
}).then(r => r.json());

// 2. Display chapters
kesfetData.chapters.forEach(chapter => {
  // Show chapter title
  // Show dersDinle section with button
  // Show soruCoz section with button
  // Show ilerleme section with retry
  // Show subChapters recursively
});

// 3. Navigation
// When user clicks "Ders Dinle"
→ window.location.href = chapter.dersDinle.navigation.clickToNavigate

// When user clicks "Soru Çöz"
```

## 🎯 User Journey

```

4. GET /kesfet/:contentId
5. Page shows:
   ├─ Book title
   ├─ All chapters (hierarchical)
   └─ For each chapter:
      ├─ Ders Dinle button → /player/chapter/:id
```
