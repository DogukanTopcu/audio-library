## 🔧 CORS ERROR - COMPLETE TROUBLESHOOTING GUIDE

### Issue
You're still getting: `Cross-Origin Request Blocked` error at `http://localhost:3001/api/auth/login`

### Root Cause
The API server needs to be **restarted** for the CORS changes to take effect.

---

## ✅ COMPLETE FIX - STEP BY STEP

### Step 1: Stop All Servers
Kill all running processes:
- Close API terminal (Ctrl+C)
- Close Admin app terminal (Ctrl+C)
- Close Web app terminal (Ctrl+C)
- Close any other node processes

### Step 2: Clear Cache & Logs
```bash
# Clear npm cache
npm cache clean --force

# Kill any remaining node processes
# On Windows:
taskkill /F /IM node.exe

# On Mac/Linux:
pkill -f node
```

### Step 3: Make Sure Database is Set Up
```bash
cd packages/db

# Check if migrations exist
npm run db:migrate

# Seed sample data
npm run db:seed

cd ../..
```

### Step 4: Start API Server (Fresh)
```bash
cd apps/api

# Clear dist folder
rm -r dist

# Install dependencies fresh
npm install

# Start in development mode
npm run start:dev
```

**WAIT** for the message:
```
API running on http://localhost:3001
Swagger UI available at http://localhost:3001/api/docs
```

### Step 5: In NEW Terminal - Start Admin App
```bash
cd apps/admin

npm install
npm run dev
```

Visit: **http://localhost:3000**

### Step 6: In NEW Terminal - Start Web App (Optional)
```bash
cd apps/web

npm install
npm run dev
```

Visit: **http://localhost:3002**

## 🎯 If Error Still Persists

### Check 1: Verify Port 3001 is Free
```bash
# On Windows:
netstat -ano | findstr :3001

# On Mac/Linux:
lsof -i :3001
```

If something is listening on 3001, kill it.

### Check 2: Check Browser Console
In browser (F12 Developer Tools):
1. Go to Console tab
2. Try to login
3. Look for error details
4. Copy exact error message

### Check 3: Check API Logs
Look at API terminal output for errors like:
- Port already in use
- Database connection failed
- Module not found

### Check 4: Verify Environment Variables
Create `.env` file in `apps/api/`:
```
NODE_ENV=development
PORT=3001
DATABASE_URL=postgresql://...
```

## 🚨 Most Common Fix

**99% of the time, the fix is:**
1. Kill API process (Ctrl+C or taskkill)
2. Wait 2 seconds
3. Start API again
4. Wait for "API running on http://localhost:3001"
5. Refresh browser
6. Try login again

Try this first before other troubleshooting!
