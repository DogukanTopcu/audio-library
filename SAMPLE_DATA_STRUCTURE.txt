### Chapter Hierarchy

```
Matematik 9 - Cebir Temelleri
├── Bölüm 1: Temel Sayı Kavramları (Main Chapter)
│   ├── Audio: Doğal Sayılara Giriş (TOPIC_INTRO, 480s)
│   ├── Audio: Tam Sayılar (TOPIC_INTRO, 420s)
│   └── 1.1 İşlemler ve Özellikleri (Sub-chapter)
│       └── Audio: Toplama İşlemi (TOPIC_INTRO, 360s)
└── Bölüm 2: Denklemler (Main Chapter)
    └── Audio: Denklem Kavramı (TOPIC_INTRO, 500s)

Fizik 10 - Hareket ve Kuvvet
├── Bölüm 1: Newton Kanunları
│   ├── Audio: Newton'un Birinci Kanunu (TOPIC_INTRO, 540s)
│   └── Audio: Newton'un İkinci Kanunu (TOPIC_INTRO, 600s)
└── Bölüm 2: Enerji
    └── Audio: Kinetik Enerji (TOPIC_INTRO, 480s)

İngilizce 11 - İşletme Dili
└── Bölüm 1: Mesleki Sohbet
    ├── Audio: Merhabalaşma (STORY_PASSAGE, 300s)
    └── Audio: İş Görüşmesi Örneği (STORY_PASSAGE, 720s)
```

### Audio Records

Each chapter has multiple audio records with:
- `title`: Descriptive name
- `type`: TOPIC_INTRO, EXPLANATION, STORY_PASSAGE, etc.
- `bucketKey`: GCP bucket path
- `durationSeconds`: Duration in seconds
- `transcript`: Full transcript text

Example audio paths:
```
audio/math9/chapter1/natural-numbers-intro.mp3
audio/math9/chapter1/integers.mp3
audio/math9/chapter1.1/addition.mp3
audio/physics10/chapter1/newton-first-law.mp3
audio/english11/chapter1/greetings.mp3
```

### Questions & Choices

For each audio record, question choices are created:
```
Question 1: [audioRecordId]
├── Choice 0: "Seçenek A" → audio/questions/choices/{id}-0.mp3
├── Choice 1: "Seçenek B" → audio/questions/choices/{id}-1.mp3
├── Choice 2: "Seçenek C" → audio/questions/choices/{id}-2.mp3 (CORRECT)
└── Choice 3: "Seçenek D" → audio/questions/choices/{id}-3.mp3

Difficulty: EASY/MEDIUM/HARD (rotating)
Topics: [chapter-title-lowercase]
```

### User Progress Data

Sample progress data for test user:

```
Completed Audio Records: ~4
   - Progressively marked as completed
   - positionSeconds: varies

Listened But Incomplete: ~4
   - Position tracked (0-100%)
   - Last updated timestamps

Question Attempts: ~6
   - Mixed correct (60%) and incorrect (40%)
   - Attempt counts: 1-3
   - Time spent: 30-180 seconds each

  selectedChoiceIndex: 1,

  timeSpentSeconds: 120,

}
```

### Activity Logs

Sample events logged:
```
PLAY_START: When user clicks play on audio
PLAY_COMPLETE: When audio finishes playing
QUESTION_CORRECT: When user answers question correctly
QUESTION_WRONG: When user answers question incorrectly
```

## Migration Files

### Initial Schema (0000_melted_thunderball.sql)
Contains all base tables and relationships

### New Tables (0001_easy_piledriver.sql)
```sql
CREATE TABLE "user_question_answers" (
  "id" uuid PRIMARY KEY DEFAULT gen_random_uuid() NOT NULL,
  "user_id" uuid NOT NULL,
  "question_id" uuid NOT NULL,
  "selected_choice_index" integer NOT NULL,
  "is_correct" boolean NOT NULL,
  "attempt_count" integer DEFAULT 1 NOT NULL,
  "time_spent_seconds" integer DEFAULT 0 NOT NULL,
  "metadata" jsonb,
  "answered_at" timestamp DEFAULT now() NOT NULL,
  "created_at" timestamp DEFAULT now() NOT NULL
);

ALTER TABLE "user_question_answers"
  ADD CONSTRAINT "user_question_answers_user_id_users_id_fk"
  FOREIGN KEY ("user_id") REFERENCES "public"."users"("id")
  ON DELETE cascade ON UPDATE no action;

ALTER TABLE "user_question_answers"
  ADD CONSTRAINT "user_question_answers_question_id_questions_id_fk"
  FOREIGN KEY ("question_id") REFERENCES "public"."questions"("id")
  ON DELETE cascade ON UPDATE no action;
```
