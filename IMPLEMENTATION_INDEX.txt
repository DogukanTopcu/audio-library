## 🔍 API Reference by Feature

### Kesfet (Browse Books)
1. List books → `GET /content` (public)
2. Get chapters → `GET /content/:id/chapters` (protected)
3. See progress % per chapter

### Ders Dinle (Listen to Audio)
1. Get audio token → `GET /player/token` (protected)
2. Stream audio to player
3. Update progress → `PATCH /player/progress` (protected)
4. View chapter completion → `GET /player/progress/chapter/:id` (protected)

### Soru Çöz (Solve Questions)
1. Get chapter questions → `GET /questions/chapter/:id` (protected)
2. Display 4 audio choices
3. Submit answer → `POST /questions/:id/answer` (protected)
4. Show if correct/incorrect
5. Offer explanation if wrong

### İlerleme (Track Progress)
1. Dashboard stats → `GET /ilerleme/statistics` (protected)
2. Per-content progress → `GET /ilerleme/contents` (protected)
3. Chapter breakdown → `GET /ilerleme/contents/:id/chapters` (protected)
4. Retry questions → `GET /ilerleme/retry-questions` (protected)

## 🛠️ Technology Stack

- **Backend**: NestJS (Node.js)
- **Database**: PostgreSQL with Drizzle ORM
- **Authentication**: JWT tokens
- **File Storage**: Google Cloud Storage (signed URLs)
- **Vector DB**: pgvector (prepared for ML)
- **ORM**: Drizzle (type-safe)
- **Language**: TypeScript

## 🎓 User Workflows

### Student Learning Flow
1. Login → Browse books (Kesfet) → Select book → View chapters
2. Click chapter → Audio player opens → Listen & track progress
3. Practice questions → Answer & submit → See result
4. View progress → Check ilerleme page → Retry incorrect Qs

### Progress Tracking Flow
1. Every audio listen tracked (position + duration)
2. Every question answer tracked (correct/incorrect + time)
3. Completion % calculated per chapter
4. Success rate calculated per chapter
5. Incorrect questions aggregated for retry

## 🔧 Maintenance & Updates

### To Add New Book
1. Insert into `content` table
2. Add chapters to `chapters` table
3. Add audio records to `audio_records` table
4. Add questions to `questions` table
5. Add choices to `question_choices` table

### To Update Progress Tracking
1. Modify `userProgress` schema for new fields
2. Modify `userQuestionAnswers` schema if needed
3. Update endpoints in player/progress controllers
4. Generate migration: `npm run db:generate`
5. Run migration: `npm run db:migrate`

### To Add New Endpoint
1. Add method to appropriate controller
2. Add route decorator (@Get, @Post, etc.)
3. Add response type documentation
4. Update API_IMPLEMENTATION.txt
5. Add curl example to API_TESTING_GUIDE.txt
